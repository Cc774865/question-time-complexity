# 题目时间复杂度 τ 的计算方法

本文是计分的正本。技能 `SKILL.md`、对照表 `spec/type-rules.md` 和代码 `src/problem_time/calibration.py` 都按这里执行。星级、文档顺序、解析字数都不是输入。

τ 是一道题在本题使用年级下的难度刻度，没有单位。它不是墙钟秒数，也不是算法复杂度的大 O。τ 只用本年级知识库、题面结构和课内熟悉度计算；它的数值用于卷内排序和例练合套。

## 1. 什么可以进入公式

只使用题干里看得到、并且正确解法必须经过的数学结构：

- 必用的核心知识块，以及这一步是直接执行、逆向识别，还是构造 / 分类；
- 从已知推到结论不可省略的变形或推导；
- 这些步骤带来的算术、代数运算负荷；
- 结构本身造成的陷阱（漏一支、变号、单位不能相加、动态单位「1」、必须换元否则做不完）。

下列内容一律不进入计数：

| 不用的东西 | 原因 |
|---|---|
| 题目在文件中的先后顺序 | 同一题面换位置必须得到同一个 τ |
| 星级、例/练标签 | 标签是教研编排，不是题面结构；只在算完后做对照 |
| 解析写了多少句、多少字 | 同一结构可以写得很短，也可以写得很长 |
| 答案的数字本身有多大 | 只在它真的增加运算步数时才计入计算复杂度 |
| 学生或模型的真实作答时长 | 当前样本是结构推出来的；有实测后再替换，不与估算混写 |

题干缺失时记 `blocked`。1、2、3 年级的看图数数、读数按 [`docs/低年级看图认数.md`](低年级看图认数.md) 计数。这条不进入其他年级，也不进入这三年级里的其他题。其余图里读不出数字、但解析里的公式能还原时，按 [`docs/图形题按解析计分.md`](图形题按解析计分.md) 用解析计数，不把还原后的式子写回文件。解析也读不出来时记 `blocked`，写明原因，不补一个数。

## 2. 从题面到 τ

```text
题干
  → 结构计数 (P, R, C, E)，再按课内模型写入熟悉度 F；未命中则 F = 0
  → 归一化后加权，得到综合分 D
  → 映射到固定难度刻度，得到 τ
  → 可选地报告本题年级工作量 t_g；它不参与 τ 或星级
```

多题放在一起时，整套 τ 是各题 τ 的算术平均（各题权重默认都是 1）。因为每题的 τ 只依赖自己的结构和熟悉度，打乱题目顺序后再平均，整套 τ 与每一题的 τ 都不变。

## 3. 五个维度

\(P\)、\(R\)、\(C\)、\(E\) 是结构计数，不是 0 到 1 的主观打分。先按下面的规则加总，再在第 4 节除以上限。\(F\) 不数步骤，取值见 3.5。

\(P\)、\(R\)、\(C\)、\(E\) 的权重与上限和 `k12-difficulty-calibration` 无历史正确率时的四维权重一致，计数方式不同：那里按解析句号数步并且 6 步封顶，这里只数必经结构，推理链上限放到 12，避免中等题和高年级题在推理维上同时顶满。这四个权重加起来是 1。\(F\) 以 0 为中心，权重 0.18，不从那四个里扣。

| 维度 | 符号 | 上限 | 权重 | 在量什么 |
|---|---|---:|---:|---|
| 前置深度 | \(P\) | 6 | 0.18 | 启动这道题要调用的知识块，加上认知层级 |
| 推理链 | \(R\) | 12 | 0.31 | 不可省略的变形、推导、筛选 |
| 计算复杂度 | \(C\) | 10 | 0.25 | 算术与代数运算负荷 |
| 易错点 | \(E\) | 6 | 0.26 | 结构性陷阱的个数，不是粗心 |
| 课内熟悉度 | \(F\) | 6 | 0.18 | 同样步数下，课内熟为负，不常见变形为正 |

### 3.1 前置深度 \(P\)

\[
P = k_{\mathrm{kp}} + b_{\mathrm{cog}}
\]

\(k_{\mathrm{kp}}\) 是题干点名或正确解法必用的核心知识块数，对照 `knowledge/topics.json` 与 `knowledge/prerequisites.json`，通常落在 1 到 4：

| 知识块尺度 | \(k_{\mathrm{kp}}\) |
|---|---|
| 单一运算或直接代入（竖式一位乘法、同分母加减、把数代进已给公式） | 1.0 |
| 进位链、商不变、乘法分配律、异分母通分 | 1.5 ~ 2.0 |
| 逆向提公因数、拆数凑整、单位「1」与具体量辨析、等腰加三边关系 | 2.5 ~ 3.5 |
| 双行部分积竖式谜、周期分解、裂项、多层动态单位「1」、二次全等或自主辅助线模型 | 3.8 ~ 5.6 |

\(b_{\mathrm{cog}}\) 只加一次，取解题所需要的最高层级：

| 认知层级 | 加多少 | 什么样的题 |
|---|---:|---|
| 直接执行 | +0.5 | 公式已给，代入即可；同分母按图填写 |
| 逆向或找隐藏结构 | +1.0 | 要先看出整体、公因数、通项，题干没有把这一步写出来 |
| 多步构造、辅助线、分类 | +1.5 ~ +2.0 | 绝对值分两支、换元、自己添辅助线、分类证明 |

知识块按「缺了它就做不对」来数，不按解析里出现过的名词来数。题干已经写明「互为相反数、互为倒数」，这三块仍然要计，因为求值必须用到它们；但不再因为解析把定义复述了一遍而加分。

辅助线模型不按条数机械加熟悉度难度。第一条关键线体现模型识别；同一模型里重复作
同方向、同用途的线主要增加执行步骤；动点分类、不同用途的新线和跨模型组合仍是新推理。

### 3.5 课内熟悉度 \(F\)

同样的知识块和推理步数，课内熟模型与不常见变形的实际启动难度差大约一档。这一档单独记在 \(F\) 上，不改写 \(P\)。\(P\) 贴近 0 或 6 时，也不会把这一档挡住。

`知识库/课内模型/` 按人教版 1–9 年级保存模型摘要。中等或高置信命中时按下表写入 \(F\)。低置信、没有命中、模型库不完整，以及高考冲刺，\(F\) 保持 0。中考冲刺按 7、8、9 年级写入 \(F\)，取更不熟的一档。

| 熟悉度 | \(F\) |
|---|---:|
| 课内熟，更早学过且本年级仍在用 | \(-1.5\) |
| 本年级核心模型 | \(-0.75\) |
| 本年级第一次系统学习 | \(0\) |
| 知识点学过，但是不常见变形 | \(+1.5\) |
| 本年级还没学到 | \(+2.0\) |

课内熟和不常见变形相差 3。\(F\) 与 \(P\) 同一把尺子（权重 0.18、上限 6），所以 \(D\) 相差 9，\(\tau\) 大约相差 0.0307。共享年级取适用年级里更不熟的那一档。

### 3.2 推理链 \(R\)

每一步都必须是换一条路就不再是同一解法的步骤。把同一通分写成两行，仍然是一步。

| 结构 | 记多少 |
|---|---:|
| 凑整配对、同乘同除 | 每处 +1 |
| 展开，或逆向提取公因数 | 每次 +1.5 |
| 先拆数才能造出公因数或倒数（\(96=24\times4\)、除以 \(\frac{9}{7}\) 改乘 \(\frac{7}{9}\)） | 每次 +2 |
| 竖式谜的一个待定空位 | +1 |
| 用首位、尾数、奇偶、位数上下界压缩候选 | 每次 +1.5 |
| 筛完仍要试算的候选 | 每 2 个 +1 |
| 全等、相似、容斥、倒推的一层 | +2 |
| 题干没有给出、必须自己添的辅助线 | 每条 +2 |
| 图形规律：从若干幅图写成通项 | +2，再加代入与求和各一步 |
| 选项逐一列式才能排除 | 按不可合并的情形加，不按选项个数机械加 1 |

### 3.3 计算复杂度 \(C\)

| 运算 | 记多少 |
|---|---:|
| 整数四则的一步 | +0.8 |
| 这一步里的进位或退位 | 每次 +0.3 |
| 多位数拆开、去括号变号、连除凑整 | 每步 +1.0 |
| 异分母通分、带分数与小数互化、乘倒数、约分 | 每处 +1.2 |
| 开方、解方程、四位数的恒等变形 | 每处 +1.5 ~ +2.0 |

正确路径几乎不计算时，\(C\) 就低。例如长调和先换元再相消，最后只剩一项，\(C\) 记 1，不把「如果学生逐项通分」的爆炸计算算进来。那条死路记在易错点里。

### 3.4 易错点 \(E\)

只数结构陷阱，一处记 1，轻微但真实的记 0.5。粗心（抄错一个数字）不计。

1. 连续进位、积升位、借位跨零。
2. 隐藏的 \(\times 1\)、去括号变号、提公因式时符号反了。
3. 多余条件，或单位不能与分率相加。
4. 分类讨论漏一支、伪解没剔除（三边关系、竖式首位为 0、数字重复）。
5. 动态单位「1」：下一步的分率是相对「剩下的」而不是相对原来的整体。
6. 几个模型接在一起（倍长中线之后再接等腰或相似）。
7. 通项下标错一位、整体代换时多了一个常数或系数（\(y-1\) 才等于已知的 \(x\)，不是 \(y\)）。

## 4. 综合分 \(D\) 与本题年级中心秒数

\[
d_P=\min\left(\frac{P}{6},1\right),\quad
d_R=\min\left(\frac{R}{12},1\right),\quad
d_C=\min\left(\frac{C}{10},1\right),\quad
d_E=\min\left(\frac{E}{6},1\right),\quad
d_F=\operatorname{clamp}\left(\frac{F}{6},-1,1\right)
\]

\[
D = 100\times(0.18\,d_P + 0.31\,d_R + 0.25\,d_C + 0.26\,d_E + 0.18\,d_F)
\]

\[
t_g = 18 + 8P + 12R + 8C + 10E + 8F
\]

\(t_g\) 的单位是秒，是可选的同年级工作量估计：18 秒是读题与写下答案的底数；系数 8、12、8、10、8 把五个维度换成秒。它不再进入 τ，也不决定星级排序。\(F=0\) 时，\(D\) 落在 0 到 100；熟悉度只把它再移动大约 \(-4.5\) 到 \(+6\)。

报告里的 \(D\) 保留两位小数。代码计算 τ 时使用未四舍五入的 \(D\)。

## 5. τ 的固定难度刻度

AI、低一年级和模拟作答时间已从正式计分移除。τ 只由当前使用年级的知识库、\(P,R,C,E,F\) 合成的 \(D\) 决定：

\[
\tau=\frac{50.89}{63}+0.003414285714\,D
\]

这保留已有星级分差的显示尺度：\(D\) 每加 1，τ 加约 0.0034；课内熟与不常见变形相差 3 时，\(D\) 相差 9，τ 相差约 0.0307。这里没有任何 AI 或低年级学生的时间假设。

若需要展示工作量，报告 \(\tau\cdot t_g\)；它不参与排序。整套 τ 是各题 τ 的加权算术平均，默认每题权重 1：

\[
\tau_{\mathrm{set}}=\frac{\sum_i v_i\tau_i}{\sum_i v_i}
\]

## 6. 手算两道题

下面的计数与 `examples/W3-L7L8L9-4-stem-summary.json` 一致。星级写在题号里只为了对回文件，没有参加运算。这两道手算题没有套用课内熟悉度，\(F=0\)，所以综合分与把熟悉度放进公式之前相同。

### 8.1 烤鸭：\(t=10x+10\)，\(x=5.5\)

结构：公式已经给出，代入一次，两步运算，有一位小数。

| 维 | 值 | 证据 |
|---|---:|---|
| \(P\) | 1.5 | 知识块「代数式求值」1，直接执行 +0.5 |
| \(R\) | 1.0 | 一次代入，没有要发现的隐藏结构 |
| \(C\) | 2.0 | \(10\times 5.5\) 与 \(+10\) |
| \(E\) | 0.5 | 小数点 |

\[
\begin{align*}
d_P&=1.5/6=0.25,\\
d_R&=1/12\approx 0.083333,\\
d_C&=0.2,\\
d_E&=0.5/6\approx 0.083333
\end{align*}
\]

\[
D=100\times(0.18\times 0.25+0.31\times 0.083333+0.25\times 0.2+0.26\times 0.083333)=14.25
\]

\[
t_g=18+8\times 1.5+12\times 1+8\times 2+10\times 0.5=63
\]

\[
\tau=\frac{50.89}{63}+0.003414285714\times14.25=0.856431
\]

### 8.2 长调和的差

\[
\left(1+\frac12+\cdots+\frac{1}{2014}\right)
\left(\frac12+\cdots+\frac{1}{2015}\right)
-
\left(\frac12+\cdots+\frac{1}{2014}\right)
\left(1+\frac12+\cdots+\frac{1}{2015}\right)
\]

正确路径是设两段和 \(a,b\)，展开后 \(ab\) 相消，得到 \(a-b=\dfrac{1}{2015}\)。项数到 2015，逐项通分不是可行解法。

| 维 | 值 | 证据 |
|---|---:|---|
| \(P\) | 5.0 | 展开、换元、和差三块，多步构造 +2 |
| \(R\) | 7.0 | 认出端点差、设元、写成 \(a(1+b)-b(1+a)\)、相消、得到末项 |
| \(C\) | 1.0 | 相消后只剩一项，没有通分 |
| \(E\) | 3.0 | 不换元就做不完；\(a,b\) 的端点设反；第一个因式是 \(1+b\) 不是 \(a\) |

\[
D=100\times\left(0.18\times\frac{5}{6}+0.31\times\frac{7}{12}+0.25\times 0.1+0.26\times 0.5\right)=48.5833
\]

\[
t_g=18+8\times 5+12\times 7+8\times 1+10\times 3=180
\]

\[
\tau=\frac{50.89}{63}+0.003414285714\times48.5833=0.973655
\]

同一结构如果只有四项（\(1+\frac12+\frac13\) 那一题），换元仍然可用，但直接通分也做得到，所以构造层级、推理步和陷阱都更低，τ 落到 0.944918。数字大本身不加 \(C\)，它改变的是「有没有另一条走得通的路」。

## 9. 星级

以后拿到的题目模板不再带星级。τ 的计算只依赖题面结构和知识库，不需要、也不接受星级作为输入。1、2、3 年级的看图数数、读数按 [`docs/低年级看图认数.md`](低年级看图认数.md) 计入这四个维度。其他年级和其他题型不进入这条。其余图里读不出数字时，改读解析再计入这四个维度，规则在 [`docs/图形题按解析计分.md`](图形题按解析计分.md)。排序仍是本节。

τ 全部算完之后，才给正课的例题、练题写星级。相连的一道例题和一道练题是一套，共用一个星级。作业题和晋级题不进这七档。

先把这一对收成一个 τ。两题之差小于 0.03 时取算术平均；差达到 0.03 时取较高的那个 τ。0.03 是七套定稿卷里相邻两档星级中心的间隔。

\[
\tau_{\text{套}}=
\begin{cases}
(\tau_{\text{例}}+\tau_{\text{练}})/2 & \text{当 }|\tau_{\text{例}}-\tau_{\text{练}}|<0.03\\
\max(\tau_{\text{例}},\tau_{\text{练}}) & \text{当 }|\tau_{\text{例}}-\tau_{\text{练}}|\ge 0.03
\end{cases}
\]

全卷里 τ 最低的那一道题，不论它是例题还是练题，它所在的那一套标成 2 星。有多道题并列最低时，含这些题的套里，文件里先出现的那一套是 2 星。其余各套仍按 \(\tau_{\text{套}}\) 从小到大标成 3、4、5、6、7、8 星。\(\tau_{\text{套}}\) 相同的两套，保持它们在文件里的先后，先出现的一套星级更小。对数不是 7 时，2 星仍给含最低 τ 的那一套，其余从 3 星往上逐档加 1，超过 8 的档在结果里照实写出。

代码在 `src/problem_time/stars.py` 的 `pair_tau` 与 `assign_stars`。`assign_stars` 不读取、不调用作业题和晋级赛。

作业题和晋级题只来自输入 docx。文档里没有对应标题时，不读、不计、不写进输出，也不调用 `assign_levels`。有标题时，等级是下一条，优先级高于 τ 远近。2–8 星分配完成之前，禁止做这一步，也禁止用 τ 代替内容去猜等级。`assign_levels` 在拿不到已完成的星级结果时直接报错。有无标题由 `paper_sections` 判断。

班的内容由分完的星级决定，窗口写死：

| 班 | 正课 |
|---|---|
| B | 2 星、3 星 |
| A | 3 星、4 星 |
| AA | 4 星、5 星 |
| AAA | 5 星、6 星 |
| S | 7 星、8 星 |

星级分配完成之后，把每道作业题、每道晋级赛和每一星的例题、练题比内容：知识块和解题结构最像哪一星，就记那一星。共用的那颗星归把这颗星当作上沿的班，不归把它当作下沿的下一个班。

| 内容最像 | 归入 |
|---|---|
| 2 星或 3 星 | B |
| 4 星 | A |
| 5 星 | AA |
| 6 星 | AAA |
| 7 星或 8 星 | S |

作业题可以落到 S。晋级赛没有 S 级，内容最像 7 星或 8 星时不改判到 AAA，记为晋级赛没有这一级。

页面只自动判定正课的 2–8 星。作业题和晋级题不自动归班，全部进入人工审核。人选完班型并提交之后，才写出那一份 docx。提交之前没有输出文件。

## 10. 知识库与样本在计分中的位置

`knowledge/` 用来给 \(k_{\mathrm{kp}}\) 找名字和先修，不直接换算成秒：

| 文件 | 规模 | 用途 |
|---|---|---|
| `topics.json` | 870 个数学知识点 | 确认题干用的是哪一块、属于哪个年级 |
| `prerequisites.json` | 1459 条先修 | 看这块知识前面还压着什么，避免把整条先修链都加进 \(P\) |
| `standards.json` | 752 条课标内容要求 | 核对知识块是否超出该学段 |
| `课内模型/` | 119 个 1–9 年级模型摘要 | 课内熟模型比不常见变形低大约一档；中、高置信时写入 \(F\) |

先修链本身不加进 \(P\)。会通分就默认已经会求公因数，\(P\) 只记这道题新调用的那一层。

`textbook-models/` 与知识点图谱分开。它不保存完整教材题干、选项、插图、答案或解析；
只保存独立撰写的结构摘要和教材位置。ISBN、CIP、精确版次和页码仍待版权页核验。
共享年级卷按最不熟的适用年级取值。`ZKCC` 按 7、8、9 年级取值。`GKCC` 的适用年级待定，不套用熟悉度。
低置信命中只保留候选，\(F\) 保持 0。

`references/cmath/cmath_dev.jsonl` 是 1–6 年级各约 100 道题的题面参考，用来对照年级和题型用语。它没有作答时长，不能当作 \(t_g\) 的实测样本。协议是 CC BY 4.0。

样本分两类，索引见 `docs/样本参考.md`：

1. **刻度对照**：7 套、98 题，四维计数写在 `src/problem_time/benchmark_2to8.py`，结果在 `examples/benchmark_7papers_2to8star.json`。
2. **不看星级的应用**：`examples/W3-L5L6-4-stem-summary.json`、`examples/W3-L7L8L9-4-stem-summary.json`，计数写在 `score_w3.py` 与 `score_w3_l789.py`。

## 11. 从 Word 到清单

题目文件的栏位以 [`docs/题目导入模板.md`](题目导入模板.md) 为准，原件在 `templates/题目导入模板.docx`。模板里的示范题不计分。

1. `python scripts/extract_docx.py <试卷.docx>` 导出段落、表格和图片张数。
2. 文档里若有 OMML（`<m:oMath>`）、MathType OLE（`word/embeddings/oleObject*.bin` 里的 `Equation Native`）或题干图，必须解码或读图。只读 `paragraph.text` 会丢掉分数、根号和整道图题。参考实现是 `examples/W9-zkcc-18/build_calibration_input.py`。
3. 每题记录 `source_index`（只为追溯）、题干规范化后 SHA-256 的前 16 位 `content_hash`、\(P,R,C,E,F\) 和一句证据。未命中时 \(F=0\)。
4. 核对 `detected = scored + blocked`。
5. 打乱清单再算一次。单题 τ 与整套 τ 都必须与原顺序一致。

调用入口：

```python
from problem_time.calibration import FourDimCounts, score_calibrated_problem

record = score_calibrated_problem(
    "题号",
    "题干转写",
    FourDimCounts(P, R, C, E, "结构证据", familiarity=F),
)
```

`record["tau"]` 即该题 τ。整套用 `problem_time.score.aggregate_set`。运行前把 `src` 放进 `PYTHONPATH`，或在本目录执行 `python -m src.problem_time.benchmark_2to8` 复核七套刻度卷。
