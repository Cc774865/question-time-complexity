# 人教版 1–9 年级课内模型库

这套库回答的是：**对这份试卷标明的年级而言，这种解题结构在课内有多熟悉**。
它与旁边的 [`知识点`](../知识点/README.md) 分开：

- `知识点/`：学生需要会什么知识；
- `课内模型/`：教材是否呈现、练习过这种解题模型。

同样的推理步数，课内熟模型的熟悉度 F 比不常见变形低 3，τ 大约低 0.03，也就是相邻两档星级的距离。只有中等或高置信命中才改分。F 不改写前置深度。

## 文件

| 文件 | 内容 |
|---|---|
| `sources.json` | 人教版六三制 1–9 年级上下册的来源与核验状态 |
| `manifest.json` | 年级、文件和模型总数（当前 119） |
| `model-seeds.json` | 生成器正本：119 条模型种子（不含教材题干） |
| `model.schema.json` | 模型文件的 JSON Schema |
| `grade-1/models.json` … `grade-9/models.json` | 各年级模型摘要 |

## 版权边界

这里只保存独立撰写、无法还原教材原题的内容：

- 模型名称和结构摘要；
- 题面与解法的短触发词；
- 常见变式和不常见变形的概括；
- 教材册次、章、节、页码、题号等来源定位。

不保存完整题干、选项、插图、答案或解析。公开电子教材可以用于人工核对定位，
但公开浏览不等于允许批量下载或再发布。

## 来源状态

教育部和人教社官方页面能够核验课标依据、教材系列和整体结构。ISBN、CIP、精确版次、
页码和题号必须以当地实际使用教材的版权页与正文复核。`sources.json` 中未取得版权页的
字段保持 `null`，状态为 `series_verified_bibliography_pending`，不猜填。

页码和版权页仍待核验。熟悉度分档已经进入正式计分；低置信命中不改分。

## 熟悉度

| 值 | 含义 |
|---|---|
| `introduced` | 本年级首次系统学习 |
| `core` | 本年级正文与基础练习中的核心模型 |
| `reinforced` | 更早学过，本年级继续使用 |
| `uncommon_transform` | 知识点学过，但这种重组、逆向或跨模型组合不常见 |
| `out_of_scope` | 对该年级尚未进入课内范围 |

共享年级卷采用保守口径：只要其中一个适用年级对该模型不熟，就保留更不熟的状态。`ZKCC` 按 7、8、9 年级套用。`GKCC` 的适用年级待定，不自动套用这份库。

## 辅助线

辅助线模型同时记录“发现第一条关键线”和“同用途重复作线”：

- 第一条关键辅助线体现模型识别；
- 同模型内重复作同方向、同用途的线，只增加执行负荷；
- 动点分类、不同用途的新辅助线、多层模型组合仍是新推理。

因此不能用“画了几条线”直接代替熟悉度。

## 生成与校验

在 `算法` 目录运行：

```powershell
python scripts\build_textbook_models.py
python scripts\validate_textbook_models.py
```

生成器读取 `model-seeds.json`，从知识点表取外键和章名，再写出各年级 `models.json`。
校验器检查九个年级、来源、外键、版权边界和 manifest 对账（总数须为 119）。
