# 题目导入模板

原件：[`templates/题目导入模板.docx`](../templates/题目导入模板.docx)。分档完成后只输出一个 docx，版式照 [`templates/题目输出模板.docx`](../templates/题目输出模板.docx)（`W6-L3L4-8.docx`）：课头、2 星到 8 星的例和练写在同一份文件里。作业题和晋级题也在这份输入 docx 里。输入里没有的那一块，不读，也不写进输出。

以后的题目文件按这一版式写。模板正文里的算式只示范栏位怎么排，文件自己写了：「下面的题目都只做参考模板来使用，具体题目严格按照以后的题目文件来读写。」给某一份文件计 τ 时，只读那一份文件里的题，不把模板里的示范题算进去。

以后拿到的题目模板不再带星级。τ 的计算只依赖题面结构和知识库，不需要、也不接受星级作为输入。标题里的 `N`、晋级题里的「星级」栏都是占位，计分时跳过。正课七对例题和练题的星级在 τ 算完后另写：差小于 0.03 的一对用平均 τ，差达到 0.03 的一对用较高的 τ，再按这个 τ 从小到大标成 2 到 8 星。这一步完成之前，不判断作业题和晋级赛。完成后只按内容相似度归班，窗口写死为 B(2,3)、A(3,4)、AA(4,5)、AAA(5,6)、S(7,8)：最像 2 或 3 星归 B，最像 4 星归 A，最像 5 星归 AA，最像 6 星归 AAA，最像 7 或 8 星归 S。一个班最多留一个内容，落到同一班的多于一道时全部交给人工审核。人工审核只选班型 B、A、AA、AAA、S，不写审核意见；选中后原段按原样放进该班。晋级赛没有 S。细则在 [`docs/计算方法.md`](计算方法.md) 第 9 节。

## 读题之前

输入文件里表示适用对象的只有「使用年级」这一栏。先认完这一栏，再读后面的题目。认不出来就停，不开始读题。

| 使用年级 | 含义 |
|---|---|
| L3L4 | 3年级、4年级共同使用 |
| L3 | 3年级使用 |
| L5 | 5年级使用 |
| L7L8L9 | 7年级、8年级、9年级共同使用 |
| ZKCC | 中考冲刺 |
| GKCC | 高考冲刺 |

单个 `L` 加年级数字，表示该年级使用。几个连在一起，表示这些年级共同使用，例如 `L5L6` 是 5年级、6年级共同使用。代码在 `src/problem_time/grade_use.py` 的 `read_grade_use`。

## 课头

文件开头三行：

```text
课次：W6
使用年级：L3L4
课次：8
```

文件名是这三行拼出来的，例如 `W6-L3L4-8.docx`。

这三行用来认出是哪一次课，不进入四维计数。

## 一道题里有什么

每道题都是「标题 + 题目 + 答案 + 解析」。题干和解析经常是一整段图片，文字节点里只有「题目：计算」这类话。读文件时必须把图片里的式子读出来；只读段落文字会把题干丢光。

栏位名的冒号不固定，这几种都算同一个栏：

| 栏 | 文件里出现过的写法 |
|---|---|
| 题目 | `题目：`、`题目:`、单独一行 `题目` |
| 答案 | `答案：`、`答案:`、`答案;`、单独一行 `答案` |
| 解析 | `解析：`、`解析:`、单独一行 `解析` |

答案和解析用来核对有没有把题读完整，不拿解析的字数当难度。

## 三种标题

正课，例题和练习成对出现：

```text
2星-例
题目：…
答案：…
解析：…
解题方法

2星-练
题目：…
答案：…
解析：…
解题方法
```

作业题的标题带上对应星级，题目、答案、解析各占一行：

```text
B-作业题（2星）
题目
…
答案
…
解析
…
```

样张里依次是 `B-作业题（2星）`、`A-作业题（3星）`、`AA-作业题（4星）`、`AAA-作业题（6星）`、`S-作业题（8星）`。输入 docx 没有作业题标题时，不读作业题，输出里也不写作业题。输出从输入原件复制，题目、答案、解析不改写；能改的只有星级、班级和题目顺序。

晋级题写在同一份输入文件的最后，星级写成 `2star` 这种形式。输入里没有「晋级题」时，不读晋级题，输出里也不写：

```text
晋级题
星级：2star
课件 ID：W6-L3L4-8-2star
题目类型：运算与式
题目：…
答案：…
解析：…
```

「星级」这一行不参与 τ。课件 ID、题目类型只作追溯。
