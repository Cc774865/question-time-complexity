# 图形题按解析计分

图里读不出数字时，不用那张图算 τ。改读这道题的解析，按下面四个维度计数，再走原来的排序，分成 2–8 星。

星级仍然不是输入。解析写了几行也不进入计数。输出文件仍复制原来的解析和原来的图，不改写成 LaTeX。

四维的刻度与 [`docs/计算方法.md`](计算方法.md) 第 3 节是同一套。τ 的公式、例题练题配对、以及从小到大标 2–8 星，都用该文件第 4–9 节，不另起一套。

## 1. 什么时候走这条

同时满足这两条才走：

1. 题干里有图，或者数字、字母、等号写在公式图片里，读图之后题干文字里仍然没有可用的数字。
2. 这道题有解析。解析里的公式是 Word 公式（OMML）或 MathType。前者直接读公式文字；后者从公式对象还原成式子。还原出来的式子只用于计数，不写回输出文件。

题干文字里已经有可计算的算式时，仍按题干计，不改读解析。作业题和晋级题不进这七档，仍交给人工审核。

## 2. 四个维度

只数解析里这条正确路径上不可省略的结构。同一关系写两行，仍然是一步。

### 前置深度

启动这道题必须调用的知识块，加上认知层级。知识块按「缺了它就做不对」来数，不按解析里出现过的名词来数。

| 解析里看到的 | 怎么记 |
|---|---|
| 单一运算，或把数代进已给关系 | 知识块 1.0，认知层级 +0.5 |
| 全等、相似、三边关系、中线、角平分线这类几何关系，题干已经写出做法 | 知识块按必用块数记，通常 2.5～3.5；认知层级 +1.0 |
| 二次全等，或学生必须自己添辅助线、自己分类 | 知识块 3.8～5.6；认知层级 +1.5～+2.0 |

前置深度不超过 6。

### 推理链

每一步都必须是换一条路就不再是同一解法的步骤。

| 解析里看到的 | 记多少 |
|---|---:|
| 全等、相似、容斥、倒推的一层 | +2 |
| 题干没有给出、解析里必须自己添的辅助线 | 每条 +2 |
| 三边关系、取值范围、不等式收成一条界 | +2 |
| 把已知线段或角度代进上一步的关系 | +1 |
| 选项要逐一排除，且情形不能合并 | 按情形加，不按选项个数加 |

推理链不超过 12。

### 计算

只数正确路径上的运算。图里的具体数字以解析里还原出来的式子为准。

| 解析里看到的 | 记多少 |
|---|---:|
| 整数四则的一步，例如 \(8-5\)、\(8+5\) | +0.8 |
| 这一步里的进位或退位 | 每次 +0.3 |
| 把一条线段折半、加倍，或代入后只做一次比较 | +0.8 |
| 开方、解方程、多步恒等变形 | 每处 +1.5～+2.0 |

正确路径几乎不计算时，计算就低。计算不超过 10。

### 易错点

只数结构陷阱，一处记 1，轻微但真实的记 0.5。抄错一个数字不计。

1. 范围是开区间，三边关系少算一边就会错。
2. 不等式里用的是加倍后的线段（例如 \(2AD\)），不是原线段。
3. 分类讨论漏一支，或伪解没有剔除。
4. 几个模型接在一起，例如倍长中线之后再接三边关系、等腰或相似。

易错点不超过 6。

## 3. 从四个数到 2–8 星

四个数记成 \(P, R, C, E\) 之后，与普通题相同：

\[
D = 100\times(0.18\,d_P + 0.31\,d_R + 0.25\,d_C + 0.26\,d_E)
\]

\[
t_g = 18 + 8P + 12R + 8C + 10E
\]

\[
r_{\mathrm{AI}} = \min(0.13 + 0.0027D,\ 0.95),\qquad
r_{g-1} = \min(1.28 + 0.0072D,\ 3)
\]

\[
\tau = \frac13 r_{\mathrm{AI}} + \frac{22}{63} r_{g-1} + \frac{20}{63}
\]

其中 \(d_P=P/6\)，\(d_R=R/12\)，\(d_C=C/10\)，\(d_E=E/6\)。

相连的一道例题和一道练题是一套。两题 τ 之差小于 0.03 时取算术平均；差达到 0.03 时取较高的那个 τ。全卷 τ 最低的那一道，不论例题还是练题，所在的一套是 2 星。其余各套按这个套 τ 从小到大标成 3、4、5、6、7、8 星。套 τ 相同的两套，保持它们在文件里的先后，先出现的一套星级更小。正课不是 7 对时，2 星仍给含最低 τ 的那一套，其余从 3 星往上逐档加 1。

## 4. 一道例子

倍长中线。图是三角形，\(BD=8\)、\(AC=5\) 在公式图片里，读图没有数字。解析还原成：

- \(BD=CD\)，\(ED=AD\)，\(\angle BDE=\angle CDA\)
- SAS 得到全等，于是 \(BE=AC=5\)
- 在 \(\triangle ABE\) 中用三边关系：\(AB-BE<AE<AB+BE\)
- 代入后 \(8-5<2AD<8+5\)，得到 \(1.5<AD<6.5\)

| 维度 | 计数 | 依据 |
|---|---:|---|
| 前置深度 | 3.5 | 中线、SAS 全等、三边关系；做法题干已写，认知层级取逆向 |
| 推理链 | 4 | 全等一层 +2，三边关系收成范围 +2 |
| 计算 | 2.4 | \(8-5\)、\(8+5\)、再折半，三步四则 |
| 易错点 | 1.5 | 开区间少算一边记 1；不等式里是 \(2AD\) 记 0.5 |

由此 \(d_P=0.5833\)，\(d_R=0.3333\)，\(d_C=0.24\)，\(d_E=0.25\)，\(D=33.3333\)，\(t_g=128.2\)，\(r_{\mathrm{AI}}=0.22000\)，\(r_{g-1}=1.52000\)，\(\tau=0.92159\)。

这一题的 τ 不单独决定星级。同一份文件里七对都按第 3 节算完：含全卷最低 τ 的那一套写成 2 星，其余按 \(\tau_{\text{套}}\) 从小到大写成 3–8 星。
