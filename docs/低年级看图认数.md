# 低年级看图数数、读数

这条只用于 **1 年级、2 年级、3 年级** 的看图数数、看图读数。四维刻度与 [`docs/计算方法.md`](计算方法.md) 第 3 节是同一套。算完之后的 τ、例题练题配对和 2–8 星，仍用该文件第 4–9 节。

星级不是输入。图里一共有几个物体不进入计数。数出 6 个和数出 8 个，只要数法相同，四个维度就相同。输出文件仍复制原来的图，不把图写成文字。

## 1. 写死的边界

`early_number_counts` 只有一个入口。下面两句都成立，才允许调用。少一条，这道题的四个数必须与没有这条规则时相同，走原来的题面计数或 [`docs/图形题按解析计分.md`](图形题按解析计分.md)。

1. 课头「使用年级」里的每一个年级都属于 1、2、3。`L1`、`L2`、`L3`、`L1L2`、`L2L3`、`L1L2L3` 可以。出现 4 年级或更高、`ZKCC`、`GKCC`，整份文档的每一道题都不走这条。
2. 这一道题自己是看图数数或看图读数：题干里有图，并且有数一数、数数、有几个、有几只、读数、读作这类说法。

因此：

- 4 年级及以上的看图数数、读数，不走这条。
- 1、2、3 年级里的写数、列式、计算、比多少、应用题、几何题，不走这条。
- 题干里已经有一步四则运算，不走这条。

## 2. 四个维度

只数这道题必须经过的数法。物体个数本身不加。

### 前置深度

| 题面 | \(P\) |
|---|---:|
| 只数或只读一个数 | 1.5 |
| 分成几类再数，或十个一捆再数零头 | 2.0 |
| 有挡住、重叠，要数看不见的 | 2.5 |

1.5 是认数这一块加上直接执行。分类或按捆再加半块。挡住或重叠要先看出看不见的部分，认知层级再加 1。前置深度不超过 6。

### 推理链

| 题面 | 记多少 |
|---|---:|
| 按顺序点一次 | 1 |
| 分类后再数，或先数几捆再数零头 | +1 |
| 分类和按捆都要做 | 一共 3 |
| 挡住或重叠，推断看不见的 | 一共 3 |
| 这道看图数数还要比多少 | 再 +1 |

推理链不超过 12。

### 计算

| 题面 | \(C\) |
|---|---:|
| 只得到一个数 | 0.5 |
| 数完再比多少 | 0.8 |

不按图里物体的个数加。计算不超过 10。

### 易错点

| 题面 | \(E\) |
|---|---:|
| 整齐排着，没有挡住 | 0 |
| 散落，或大小不一 | 0.5 |
| 挡住或重叠 | 1 |
| 还要分类再数 | 再 +0.5 |

抄错一个数不计。易错点不超过 6。

## 3. 然后仍按原来的公式

四个数记成 \(P, R, C, E\) 之后，与普通题相同，用 [`docs/计算方法.md`](计算方法.md) 第 4–9 节得到 τ，再和同一套的例题、练题一起排 2–8 星。
