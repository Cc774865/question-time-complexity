# 使用说明

把下面这句话发给 Cursor，就会装上这个项目并打开题目分档界面：

```text
复制 https://github.com/Cc774865/question-time-complexity.git 装到 Cursor 里，并打开界面
```

Cursor 会把仓库克隆到个人技能目录 `question-time-complexity`，安装依赖，运行 `python scripts/serve_ui.py`，并在浏览器里打开界面。地址一般是 http://127.0.0.1:8765/ 。界面只有三块：输入、输出、人工审核。计算方法不写在页面上。

自己打开时，在仓库目录执行：

```text
python -m pip install -r requirements.txt
python scripts/serve_ui.py
```

## 整份文档怎么走

1. 把题目文档放进输入。支持 docx 和 md，可以一次选多个，也可以拖进文件夹。md 用 `# 例`、`# 练`，下面分 `题干`、`答案`、`解析`。`解题方法` 不读。
2. 点**开始工作**。每一份输入各生成一份预览，都列在输出里。下载名是 `{周次}-{年级}-{课次}-预览.docx`，例如 `W9-ZKCC-18-预览.docx`。
3. 输出下面从上到下是 2 星到 8 星。拖拽只改顺序，这一步不写新文件。
4. 顺序改完后，点输出区星级列表下面的**提交**。每点一次生成一份新的预览，下载名是 `{周次}-{年级}-{课次}-预览(n).docx`。n 从 1 起，等于这个按钮点过的次数。第一次是 `预览(1)`，第二次是 `预览(2)`。
5. 人工审核只给作业题和晋级题选班型：B、A、AA、AAA、S。输入文档里没有这两块，这里就是空的。
6. 班型都选完后，点人工审核的**提交**，生成生产文档。下载名是 `{周次}-{年级}-{课次}-生产.docx`，例如 `W9-ZKCC-18-生产.docx`。还有题目没选班型时，不会生成这个文件。

开始工作给出的那份不带括号的预览会一直留在列表里。之后每次点输出区的提交，都在它下面再加一份带编号的预览。

## 输入文档

读题之前先认**使用年级**。docx 只认课头，不认文件名。md 正文写了使用年级就认正文；正文没有时，从文件名 `W3-L1-2-混合.md` 这种「周次-年级-课次」里认。

| 写法 | 意思 |
|---|---|
| `L1` | 1 年级使用 |
| `L2` | 2 年级使用 |
| `L3` | 3 年级使用 |
| `L4` | 4 年级使用 |
| `L5` | 5 年级使用 |
| `L6` | 6 年级使用 |
| `L7` | 7 年级使用 |
| `L8` | 8 年级使用 |
| `L1L2`、`L3L4`、`L5L6`、`L7L8` | 连写的这些年级共同使用 |
| `ZKCC` | 中考冲刺 |
| `GKCC` | 高考冲刺 |

大小写都可以，`zkcc` 和 `ZKCC` 是同一个。认不出来就停，不开始算。

正课里相连的例题和练题是一套。作业题、晋级题只在这份输入文档里有对应标题时才读。没有就不出现在人工审核里，也不写进结果。

原稿上印的星级不参与计算。能改的只有星级（2–8）、班型（B、A、AA、AAA、S）和题目顺序。题目、答案、解析和里面的图片按原稿复制。

读图一栏是可选项，填 DeepSeek 的 API。它只把题干图片转写成计算用的文字，不写进预览或生产文档。留空则沿用已经保存的密钥。密钥不进文档。

## 两份文档的差别

预览已经按当前 2–8 星排好正课。作业题和晋级题的标题保持原稿。

生产文档在这个顺序上写入班型。作业题标题只写成 `{班型}-作业题`，例如 `A-作业题`。晋级题标题写成 `{班型}-晋级题`，例如 `AA-晋级题`。

换一批输入文件，或在输入里移除文件之后，之前的预览和生产不再沿用。需要重新点开始工作。

## 星级

1、2、3 年级的看图数数、读数按 [`低年级看图认数.md`](低年级看图认数.md) 计。其他年级不走这条，这三年级里的其他题也不走这条。


相连的例题和练题共用一个星。两题 τ 的差小于 0.03 时用算术平均，差达到 0.03 时用较高的那个。其中单题 τ 最低的那一套定为 2 星，其余套按套 τ 从小到大排成 3、4、5…… 套 τ 相同的，文件里更靠前的一套星更低。

计算过程见 [`计算方法.md`](计算方法.md)。题干数字在图里、解析能读时，按 [`图形题按解析计分.md`](图形题按解析计分.md) 计分。版式见 [`题目导入模板.md`](题目导入模板.md)。
