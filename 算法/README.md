# 算法

这里只放可运行的计算程序：

| 位置 | 内容 |
|---|---|
| `src/problem_time` | 结构计数、课内熟悉度、τ、例练配对、星级和预览 |
| `ui` | 输入、输出、人工审核三个模块 |
| `scripts` | 界面服务，以及课内模型的生成和校验 |
| `tests` | 回归测试 |
| `spec` | 契约说明 |

知识库在上一级的 `知识库`，正确星级题在上一级的 `正确样本`。程序按目录名找到它们，不把样本读进公式。

在本目录启动界面：

```powershell
$env:PYTHONPATH = "src"
python scripts\serve_ui.py
```

浏览器打开 `http://127.0.0.1:8765`。
