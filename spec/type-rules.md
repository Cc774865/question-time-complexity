# 四维结构校准与 τ 计算规范（v3）

推导、权重来历和两道手算题写在 [`docs/计算方法.md`](../docs/计算方法.md)。本文保留甄别细则和对照表。

本规范吸收 `k12-difficulty-calibration` 的四个客观评价维度（前置深度 `prereq`、推理链 `reasoning`、计算复杂度 `compute`、易错点 `error`），修正原技能「拿解析文字长度和浅层关键词当难度、6 步即封顶」的失真问题。以后拿到的题目模板不再带星级。τ 的计算只依赖题面结构和知识库，不需要、也不接受星级作为输入。

代码实现在 `src/problem_time/calibration.py`，7 套卷完整对照数据在 `src/problem_time/benchmark_2to8.py` 与 `examples/benchmark_7papers_2to8star.json`。

## 1. 为什么直接照搬原 skill 的数法会失真

在 `W9-zkcc-18`（中考几何）与 `W5-L3L4-7`（三四年级竖式与数字谜）上实测原 skill 后，暴露出四处偶然性来源：

1. **按解析句号数步数，且 6 步封顶**：`min(steps/6, 1)` 让 3 星题与 8 星题在推理链维度都得满分 `1.0`，高星题完全拉不开。
2. **关键词词典只覆盖局部小学词**：倍长中线、全等导角、裂项相消、拆椅子造公因数、竖式进位链都不在词典里，导致 7 星、8 星题被判成 `kp_count = 0~1`。
3. **只扫普通文本节点**：Word 里的 OMML 分数（`<m:f>`）、MathType OLE 公式（`Equation Native`）与题干图片如果不先解码，分数、根号、等式全丢。
4. **用固定类型比例算 \(\tau\)**：若同一题型的 \(r_{\mathrm{AI}}, r_{g-1}\) 是常数，\(t_g\) 在比值中被约掉，同题型所有题 \(\tau\) 完全相同。

## 2. 去偶然性的四维计数甄别规则

所有计数**只看题面结构与必经数学步骤**，绝不看解析写了几句话、绝不看题目在文档中的先后顺序。

### 2.1 前置深度 `prereq`（\(P \in [0, 6]\)）

衡量「启动这道题需要调动几层前置知识与多高的思维层级」：

\[
P = \text{必用核心知识块数 } k_{\text{kp}} + \text{认知层级加权 } b_{\text{cog}}
\]

- **核心知识块 \(k_{\text{kp}}\)**（对照 `knowledge/topics.json` 与 `prerequisites.json`）：
  - 单一运算规则（如直接竖式乘法、同分母加减、直接交换凑整）：\(1.0\)
  - 含进位/退位链、商不变、标准乘法分配律、异分母通分：\(1.5 \sim 2.0\)
  - 逆向提取公因数、拆数凑整、单位“1”与具体量辨析、等腰分类+三边关系：\(2.5 \sim 3.5\)
  - 双行部分积竖式谜、周期数分解（\(1001=7\times11\times13\)）、裂项相消、多层动态单位“1”、倍长中线/截长补短/半角模型二次全等：\(3.8 \sim 5.6\)
- **认知层级 \(b_{\text{cog}}\)**：直接执行 \(+0.5\)；逆向填空/找隐藏公因数 \(+1.0\)；多步构造/辅助线/分类证明 \(+1.5 \sim 2.0\)。

### 2.2 推理链 `reasoning`（\(R \in [0, 12]\)）

衡量「从已知到结论最少要走几步不可省的数学变形或逻辑推导」（上限设为 12，防止 4 星就封顶）：

- **直接计算/巧算类**：
  - 识别凑整配对（如 \(25\times4, 125\times8\)）或同乘同除：每处计 \(1\)；
  - 展开或逆向提取公因数：每次计 \(1.5\)；
  - 隐藏公因数需要先拆数/变形（如 \(96=24\times4\)、除以 \(\frac{9}{7}\) 转乘 \(\frac{7}{9}\)、「拆椅子」\(396\times29-394\times28\)）：每次变形计 \(2\)；
- **竖式数字谜类**：
  - 每个待定空位逆推计 \(1\)；
  - 每次利用首位估值、个位尾数、奇偶性或位数上下界压缩候选集计 \(1.5\)；
  - 筛后仍需逐一试算排除的候选分支，每 \(2\) 个候选计 \(1\)；
- **应用题与几何推理/证明类**：
  - 每条必须接入推导链的原子条件转换（中点→线段相等、平行→内错角、余下分率转换）计 \(1\)；
  - 每次全等/相似判定或容斥/倒推层级计 \(2\)；
  - 题干未给、必须自主添出的辅助线（倍长、截长、补短、作高）每条计 \(2\)。

### 2.3 计算复杂度 `compute`（\(C \in [0, 10]\)）

衡量「算术与代数运算本身的负荷」：

- 一位数乘法或整数加减：每步计 \(0.8\)，每次进位/退位加 \(0.3\)；
- 多位数拆数分配、去括号变号、连除凑整：每步计 \(1.0\)；
- 异分母通分、带分数与小数互化、分数除法乘倒数、约分：每处计 \(1.2\)；
- 勾股定理开方、解一元/二元方程、四位数代数恒等变形：每处计 \(1.5 \sim 2.0\)。

### 2.4 易错点 `error`（\(E \in [0, 6]\)）

只数**结构性陷阱**，不数粗心：

1. **连续进位 / 积升位 / 借位跨零**（如 \(624\times5=3120\)）；
2. **隐藏系数或符号反转**（如 \(125\times7+125\) 漏掉 \(\times1\)、除号后去括号漏变号、\(98\times7=(100-2)\times7\) 符号错）；
3. **多余干扰数据或单位陷阱**（如给“重 \(\frac{1}{20}\) 千克”却问“占几分之几”，或既问分率又问具体米数）；
4. **分类讨论与伪解剔除**（如等腰三角形两腰为 \(\frac{1}{3}\) 时不满足三边关系、竖式谜首位不为 0 或数字不重复）；
5. **动态基准切换**（如每次“余下的 \(\frac{a}{b}\) 再加减常数”）；
6. **多模型耦合**（如倍长中线后再接二倍角等腰与子母相似）。

## 3. 从四维计数到综合分 \(D\)、中心耗时 \(t_g\) 与 \(\tau\)

### 3.1 四维归一化与综合难度分 \(D \in [0, 100]\)

沿用 `k12-difficulty-calibration` 无历史数据时的四维权重：

\[
w_P = 0.18,\quad w_R = 0.31,\quad w_C = 0.25,\quad w_E = 0.26
\]

\[
d_P = \min\!\left(\frac{P}{6}, 1\right),\quad
d_R = \min\!\left(\frac{R}{12}, 1\right),\quad
d_C = \min\!\left(\frac{C}{10}, 1\right),\quad
d_E = \min\!\left(\frac{E}{6}, 1\right)
\]

\[
D = 100\times(0.18\,d_P + 0.31\,d_R + 0.25\,d_C + 0.26\,d_E)
\]

### 3.2 本题年级基准中心耗时 \(t_g\)

\[
t_g = 18 + 8P + 12R + 8C + 10E \quad (\text{seconds})
\]

### 3.3 相对耗时比与时间复杂度 \(\tau\)

题目结构越复杂（\(D\) 越高），AI 相对本题年级学生的速度优势越小（\(r_{\mathrm{AI}}\) 上升），低一年级学生相对本题年级越吃力（\(r_{g-1}\) 上升）：

\[
r_{\mathrm{AI}}(D) = \min(0.13 + 0.0027\,D,\; 0.95),\qquad
r_{g-1}(D) = \min(1.28 + 0.0072\,D,\; 3.00)
\]

用确定性 10 组倍率 `SAMPLE_FACTORS` 生成三因子样本并经几何平均与中位数 25% 校验后，三因子合成权重保持不变：

\[
w_{\mathrm{AI}}=\frac{1}{3},\qquad
w_g=\frac{1-w_{\mathrm{AI}}}{2.1}=\frac{2}{6.3},\qquad
w_{g-1}=1.1\,w_g=\frac{2.2}{6.3}
\]

\[
\tau = w_{\mathrm{AI}} T_{\mathrm{AI}} + w_{g-1} T_{g-1} + w_g
\]
